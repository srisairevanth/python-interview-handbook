01interpreter · names · indentation · docstrings5 questions

Syntax, Names & the First Program

How Python runs your code, indentation as syntax, names as references, input and output, docstrings, and the conventions interviewers notice.

What runs when you run a file

CPython, the reference implementation, compiles each module to bytecode and then a virtual machine executes that bytecode. Compiled bytecode is cached in __pycache__ as .pyc files, which is why the first import of a big module is slower than later ones. You never write machine code, and the same .py file runs on any platform that has the interpreter.

The first program

Python verified run
name = "Asha"
print("Hello,", name)
Output
Hello, Asha

Names are labels, not boxes

Assignment binds a name to an object. It never copies the object. Two names can point at the same list, so a change made through one is visible through the other.

Python verified run
x = [1, 2, 3]
y = x
y.append(4)
print(x, x is y)
Output
[1, 2, 3, 4] True

Indentation is syntax

A block is defined by its indentation, and the convention is four spaces per level. The colon at the end of if, for, def and class opens the block.

Python
def classify(n):
    if n < 0:
        return "negative"
    elif n == 0:
        return "zero"
    return "positive"

Input and output

input() always returns a str, so numbers need an explicit conversion. print separates its arguments with a space and ends with a newline, and both can be changed.

Python
age = int(input("Age: "))
print("Next year:", age + 1, sep=" ", end="!\n")

Docstrings

Python verified run
def area(width, height):
    """Return the area of a rectangle."""
    return width * height

print(area(3, 4), area.__doc__)
Output
12 Return the area of a rectangle.

Interview questions

QIs Python compiled or interpreted?

Both, in two steps. CPython compiles source to bytecode, caches it in __pycache__, and a virtual machine executes that bytecode. There is no separate machine-code build step for the program you write.

QWhat does if __name__ == "__main__": do?

When a file runs directly, its __name__ is the string "__main__". When another module imports it, __name__ is that module's own name. The guard lets one file be both a script and an importable module without running its demo code on import.

QWhat is PEP 8?

The official style guide: four-space indentation, snake_case for functions and variables, CapWords for classes, UPPER_CASE for constants, and lines short enough to read side by side in a review.

QIs Python dynamically typed, and is it strongly typed?

Dynamically typed means names carry no declared type while objects do, and types are checked as the program runs. Strongly typed means the interpreter will not silently mix incompatible types: "1" + 1 raises a TypeError instead of guessing what you meant.

QWhat is a docstring, and where does it live?

A string literal placed as the first statement of a module, class or function. It is stored in __doc__ and shown by help(), so it is the right place to state what the function promises to do.

PitfallMixing tabs and spaces

Python 3 refuses to guess how wide a tab is. A file that mixes them raises TabError or IndentationError. Configure the editor to insert four spaces and never mix the two.

RememberNames are references

Assignment never copies. b = a makes two names for one object. To get an independent copy of a list, use a[:], a.copy() or copy.deepcopy, and choose deliberately.

02int · float · bool · None · is versus == · truthiness6 questions

Data Types, Objects & Identity

Everything is an object with an identity, a type and a value. Covers unbounded integers, binary floats, bool as a subclass of int, is versus ==, and which values are falsy.

Everything is an object

Every value is an object. It has a type, a value and an identity, which id() reports. type() gives the class, and isinstance() also accepts subclasses, which is usually what you want.

Python verified run
x = 42
print(type(x))
print(isinstance(True, int))
print(type(3.14), type(True), type(None))
Output
<class 'int'>
True
<class 'float'> <class 'bool'> <class 'NoneType'>

Integers and floats

int has no fixed size. Arithmetic on large values just uses more memory. float is an IEEE 754 double, which keeps about 15 to 17 significant decimal digits, so some decimal fractions cannot be stored exactly.

Python verified run
print(2 ** 100)
print(0.1 + 0.2)
print(0.1 + 0.2 == 0.3)
print(7 / 2, 7 // 2, -7 // 2, -7 % 3)
Output
1267650600228229401496703205376
0.30000000000000004
False
3.5 3 -4 2

Note the division rules: / always gives a float, // floors toward negative infinity, and % takes the sign of the divisor.

is versus ==

== asks whether two values are equal, by calling __eq__. is asks whether they are the same object. Use is for None and for sentinel objects, and == for everything else.

Python verified run
a = [1, 2]
b = [1, 2]
c = a
print(a == b, a is b, a is c)
Output
True False True

Truthiness

Every object has a truth value. Zero, empty containers, empty strings and None are false. Almost everything else is true, including the string "0".

Python verified run
for value in [0, 0.0, "", [], {}, None, "0", [0]]:
    print(repr(value), bool(value))
Output
0 False
0.0 False
'' False
[] False
{} False
None False
'0' True
[0] True

Rounding

round() uses banker's rounding: halves go to the nearest even number.

Python verified run
print(round(2.5), round(3.5))
Output
2 4

Interview questions

QWhat is the difference between is and ==?

== compares values by calling __eq__. is compares identity, meaning the two names refer to the same object in memory. Two equal lists are == but not is.

QWhy is 0.1 + 0.2 != 0.3 in Python?

Binary floating point cannot represent 0.1 exactly, so the sum is slightly above 0.3. Compare floats with math.isclose, and use decimal.Decimal when exact decimal arithmetic matters, such as money.

QAre Python integers bounded?

No. They grow as far as memory allows. Converting a very large integer to a decimal string is limited by default to 4300 digits since Python 3.11, which protects against slow quadratic conversions; sys.set_int_max_str_digits changes the limit.

QWhich values are falsy?

False, None, zero of any numeric type, and empty strings, lists, tuples, dicts and sets. A class is falsy when it defines __bool__ returning False or __len__ returning 0.

QIs bool a subclass of int?

Yes. True equals 1, so True + True is 2. That is why isinstance(True, int) is True, and why a check for integers sometimes needs to exclude booleans explicitly.

QWhat is the small-integer cache?

CPython keeps shared objects for integers from -5 to 256, so is happens to work for them. That is an implementation detail. Never rely on identity for numbers; compare with ==.

Pitfallis with a literal

x is 5 looks like a comparison by value but tests identity. Modern Python warns about it with a SyntaxWarning. Use x == 5.

RememberNumeric types at a glance

int is unbounded and exact. float is binary and approximate. bool is a subclass of int. decimal.Decimal is exact in base ten.

03immutable str · slicing · f-strings · join · encode4 questions

Strings & Formatting

Immutability and what it costs, slicing, joining versus concatenating, f-strings and their format specifiers, and the boundary between str and bytes.

Strings are immutable

Methods such as upper, replace and strip return a new string. The original is untouched. Item assignment is not allowed at all.

Python verified run
s = "python"
t = s.upper()
print(s, t)
try:
    s[0] = "P"
except TypeError as err:
    print("TypeError:", err)
Output
python PYTHON
TypeError: 'str' object does not support item assignment

Slicing

s[start:stop:step] builds a new string. Negative indices count from the end, and a missing bound means the edge of the string.

Python verified run
word = "interview"
print(word[0], word[-1], word[2:6], word[::-1], word[::2])
Output
i w terv weivretni itriw

Joining instead of concatenating

Joining a list of pieces is linear in the total length. Repeated += on an immutable string can copy the whole prefix at every step.

Python verified run
parts = ["a", "b", "c"]
print("-".join(parts))
Output
a-b-c

f-strings and format specifiers

Python verified run
name, score = "Ravi", 91.456
print(f"{name:>8} | {score:.1f}")
print(f"{score=}")
print("{} scored {:.0f}".format(name, score))
Output
    Ravi | 91.5
score=91.456
Ravi scored 91

The = specifier, added in Python 3.8, prints both the expression and its value, which is handy for quick debugging.

Bytes and encoding

Python verified run
text = "héllo"
data = text.encode("utf-8")
print(len(text), len(data), data)
print(data.decode("utf-8") == text)
Output
5 6 b'h\xc3\xa9llo'
True

Interview questions

QWhy are strings immutable?

Immutability makes a string safe to share between names and threads, lets it be used as a dictionary key, and gives it a hash that never changes. Operations return new strings, so a value cannot change under a reference that holds it.

QWhy is "".join(items) preferred to += in a loop?

Each += on a string can allocate a new string and copy everything built so far, so the total work grows quadratically. join computes the final length once and copies each piece once. CPython has an optimisation for some += cases, but do not rely on it in an interview answer.

QHow do you check whether a string is a palindrome?

s == s[::-1] is the idiomatic answer. It runs in O(n) time and uses O(n) extra space for the reversed copy. A two-pointer loop from both ends does the same work in O(1) extra space, which is worth mentioning.

QWhat is the difference between str and bytes?

str is text, a sequence of Unicode code points. bytes is a sequence of raw eight-bit values. encode turns text into bytes with a chosen codec, and decode reverses it. Mixing the two raises TypeError.

PitfallMethods return new strings

s.strip(), s.replace(...) and s.upper() do not change s. Writing them without assigning the result is a silent no-op. Assign the result, or return it.

RememberFormatting choices

f-strings are the default for Python 3.6 and later, because they are fast and readable. Use str.format only when the template comes from outside the code.

Control Flow & Comprehensions

Loops with else, range, enumerate and zip, list, set, dict and generator comprehensions, and structural pattern matching with match.

Loops with else

The else block of a loop runs only when the loop ends without break. It is the clean way to write "search, and handle not found".

Python verified run
for n in [3, 5, 8, 9]:
    if n % 2 == 0:
        print("first even:", n)
        break
else:
    print("no even number")
Output
first even: 8

range, enumerate and zip

Python verified run
names = ["ana", "ben", "cy"]
scores = [88, 92, 79]
for i, name in enumerate(names, start=1):
    print(i, name)
print(list(zip(names, scores)))
print(list(range(10, 0, -3)))
Output
1 ana
2 ben
3 cy
[('ana', 88), ('ben', 92), ('cy', 79)]
[10, 7, 4, 1]

Comprehensions

Python verified run
squares = [x * x for x in range(6) if x % 2 == 0]
print(squares)
print({c: len(c) for c in ["go", "java", "python"]})
print({n % 3 for n in range(10)})
print(sum(x for x in range(5)))
Output
[0, 4, 16]
{'go': 2, 'java': 4, 'python': 6}
{0, 1, 2}
10

The last line uses a generator expression. Parentheses build a lazy generator, so nothing is stored in memory.

Pattern matching

Python verified run
def describe(status):
    match status:
        case 200 | 201:
            return "ok"
        case 404:
            return "not found"
        case _:
            return "other"

print(describe(201), describe(404), describe(500))
Output
ok not found other

Interview questions

QWhat does else on a loop do?

It runs when the loop finishes without hitting break. It is useful for search loops, where the else branch means nothing matched. It does not run after break, and continue has no effect on it.

QDo comprehension variables leak into the enclosing scope?

Not in Python 3. A comprehension has its own scope, so its loop variable is gone after the expression. Python 2 leaked list-comprehension variables, which is a known trap in old code.

QWhy is x in range(...) fast?

For integers, range tests membership arithmetically in constant time instead of scanning. range also uses constant memory however large it is, so prefer it to list(range(...)).

QHow does a list comprehension differ from a generator expression?

Brackets build the whole list immediately. Parentheses build a generator that yields one value at a time, so memory stays constant and values are computed on demand. The generator can be consumed only once.

QWhat is match for?

Structural pattern matching, added in Python 3.10. It is more than a switch: cases can unpack sequences and mappings, bind names and check classes. It does not fall through, so there are no break statements.

PitfallIndexing when you only need the values

for i in range(len(items)) followed by items[i] is slower and harder to read than iterating directly. Use for item in items, or enumerate when the index is needed.

05def · defaults · *args · **kwargs · closures · LEGB6 questions

Functions, Scope & Arguments

Default arguments are evaluated once, *args and **kwargs, name lookup with LEGB, closures and late binding, and positional-only and keyword-only parameters.

Default arguments are evaluated once

The default value is created when the def statement runs, not on each call. A mutable default is therefore shared between calls.

Python verified run
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket

print(add_item(1))
print(add_item(2))
Output
[1]
[1, 2]

The fix is a sentinel: use bucket=None and create the list inside the function.

*args and **kwargs

Python verified run
def report(title, *values, sep=", ", **meta):
    print(title, sep.join(map(str, values)), meta)

report("sizes", 1, 2, 3, unit="cm", source="survey")
Output
sizes 1, 2, 3 {'unit': 'cm', 'source': 'survey'}

Scope: LEGB, global and nonlocal

Name lookup checks Local, then Enclosing functions, then Global, then Built-in names. Assignment creates a local name unless you declare otherwise.

Python verified run
x = "global"

def outer():
    x = "enclosing"
    def inner():
        nonlocal x
        x = "changed"
    inner()
    return x

print(outer(), x)
Output
changed global

Closures and late binding

A closure remembers variables from the scope where it was created. Lambdas created in a loop all share the same loop variable, so they see its final value.

Python verified run
funcs = [lambda: i for i in range(3)]
print([f() for f in funcs])

funcs = [lambda i=i: i for i in range(3)]
print([f() for f in funcs])
Output
[2, 2, 2]
[0, 1, 2]

Positional-only and keyword-only parameters

Python verified run
def f(a, /, b, *, c):
    return a + b + c

print(f(1, 2, c=3))
Output
6

Parameters before / must be passed by position. Parameters after * must be passed by keyword.

Interview questions

QWhat is the mutable default argument trap?

Default values are evaluated once, when def runs, so a default list or dict is shared by every call that relies on it. Use None as the default and create the object inside the function.

QIs Python pass-by-value or pass-by-reference?

Neither exactly. It is call by object reference, sometimes called pass-by-sharing. The function receives a reference to the same object, so mutating it is visible to the caller. Rebinding the parameter to a new object is not visible outside the function.

QExplain LEGB.

Lookup searches Local, then Enclosing function scopes, then Global, then Built-in names, and stops at the first match. nonlocal and global let an inner function rebind a name from a wider scope. Without them, assignment creates a new local name.

QWhat is the difference between *args and **kwargs?

*args collects extra positional arguments into a tuple, and **kwargs collects extra keyword arguments into a dict. At a call site, * and ** do the reverse: they unpack an iterable or a mapping into separate arguments.

QWhat does global do?

It makes assignment inside the function rebind the module-level name. Reading a global needs no declaration. Heavy use of global makes code hard to reason about, so pass values in and return results instead.

QWhen should you avoid a lambda?

A lambda holds exactly one expression and no statements. Use a named def when the function needs a name in tracebacks, a docstring, more than one line, or reuse in several places.

PitfallLate binding in loops

Closures capture variables, not values. Creating lambdas in a loop without binding the current value as a default argument gives every function the final value.

RememberParameter order

Positional-only parameters come first, before /. Ordinary parameters come next. Keyword-only parameters come after *. *args and **kwargs come last.

06dynamic arrays · hash tables · complexity · copying · sorting6 questions

Lists, Tuples, Sets & Dicts

Lists are dynamic arrays, sets and dicts are hash tables. Covers complexity, hashability, shallow versus deep copies, insertion order, and sorting with a key.

What the containers are built on

A list is a dynamic array of references: indexing is O(1), appending is amortised O(1), and inserting or deleting in the middle shifts every later element. A dict and a set are hash tables: a key's hash chooses where it lives, so lookup, insertion and deletion are O(1) on average. Dicts keep insertion order. Sets do not promise any order.

Only hashable objects can be dictionary keys or set members. A hashable object has a hash that never changes during its lifetime, and it compares equal to other objects with the same hash when they are equal.

Sorting with a key

sorted returns a new list and accepts any iterable. list.sort sorts in place and returns None. Both are stable, so items with equal keys keep their original order.

Python verified run
people = [("ana", 31), ("bo", 25), ("cy", 31)]

['A', 'b', 'c']

Changing a list while looping over it

Removing items from a list during a for loop skips the element that slides into the removed slot.

Python verified run
items = [2, 4, 6, 7]
for x in items:
    if x % 2 == 0:
        items.remove(x)
print(items)
Output
[4, 7]

Interview questions

QHow does a dictionary lookup work?

The key's hash picks a starting slot in the table. CPython probes from there and compares keys with == when the hashes match. The average cost is O(1). Keys must be hashable, and their hash must not change while they are stored in the dict.

QWhy are tuples hashable but lists are not?

A tuple of hashable items cannot change, so its hash can stay fixed. A list can change, and a hash that changed after insertion would make lookups fail. That is why {[1, 2]: "x"} raises TypeError: unhashable type: 'list'.

QWhen would you use a list, a tuple, a set or a dict?

A list for an ordered, mutable sequence. A tuple for a fixed record, or as a dict key because it is immutable. A set for uniqueness and fast membership tests. A dict to map keys to values.

QWhat is the difference between list.sort() and sorted()?

list.sort() sorts in place and returns None. sorted() returns a new list and works on any iterable. Both use Timsort, which is stable and fast on partly sorted data.

QAre dicts ordered?

Yes. Since Python 3.7, a dict keeps insertion order and the language guarantees it. Sets make no ordering promise and cannot be indexed.

QWhy is x in some_list slow for large lists?

It scans element by element, so it is O(n). If you test membership many times, build a set once. Each test then averages O(1).

PitfallShallow copies share nested objects

grid[:] copies one level. Nested lists and dicts are shared between the copies. Use copy.deepcopy for nested data that must stay independent.

Rememberdict.get and setdefault

d.get(k, default) reads without raising KeyError and leaves the dict unchanged. d.setdefault(k, default) also stores the default when the key is missing.

collections, heapq & bisect

The standard-library containers and algorithms that show up in interview code: counting, grouping, queues, priority queues and binary search on sorted lists.

Counter and defaultdict

Python verified run
from collections import Counter, defaultdict

words = "the cat and the hat and the bat".split()
print(Counter(words).most_common(2))
groups = defaultdict(list)
for w in words:
    groups[len(w)].append(w)
print(dict(groups))
Output
[('the', 3), ('and', 2)]
{3: ['the', 'cat', 'and', 'the', 'hat', 'and', 'the', 'bat']}

deque for queues

deque gives O(1) appends and pops at both ends. Read the output carefully: print renders its arguments only after every argument has been evaluated, so the queue is already smaller when it prints.

Python verified run
from collections import deque

q = deque([1, 2, 3])
q.append(4)
q.appendleft(0)
print(q, q.popleft(), q.pop())
Output
deque([1, 2, 3]) 0 4

heapq: a min-heap

Python verified run
import heapq

nums = [5, 1, 8, 3]
heapq.heapify(nums)
print(heapq.heappop(nums), nums[0])
print(heapq.nlargest(2, [5, 1, 8, 3]))
Output
1 3
[8, 5]

bisect on a sorted list

Python verified run
import bisect

sorted_nums = [1, 3, 3, 7]
print(bisect.bisect_left(sorted_nums, 3), bisect.bisect_right(sorted_nums, 3))
bisect.insort(sorted_nums, 5)
print(sorted_nums)
Output

[1, 3, 3, 5, 7]

Interview questions

QWhy use deque for a queue instead of a list?

append and popleft are O(1) on a deque. Removing from the front of a list with pop(0) shifts every remaining element, which is O(n). A breadth-first search on a large graph slows badly with a list.

QHow do you build a max-heap in Python?

heapq provides only a min-heap. For numbers, push negated values. For anything else, push (-priority, item) tuples, or (priority, counter, item) so that equal priorities never compare the items themselves.

QWhat does defaultdict do that a plain dict does not?

It creates a default value the first time a missing key is read or written, using a factory such as list or int. That removes the if key not in d branch from grouping and counting loops.

QWhen would you reach for Counter?

To count hashable items. most_common(k) returns the top k. Counters also support addition, subtraction and intersection, which makes frequency and anagram problems short.

PitfallHeap ties compare the next field

A heap of tuples compares the second field whenever the first fields are equal. If the second field is not orderable, such as a dict, the comparison raises TypeError. Add a unique counter as a tie-breaker.

Rememberbisect and insort

bisect finds a position in O(log n). insort also inserts, but the shift makes the insertion O(n) in the worst case, so it is best for modest sizes.

        return isinstance(other, Point) and (self.x, self.y) == (other.x, other.y)

QWhat is self?

The instance the method was called on. Python passes it automatically, so obj.method(x) is the same as Class.method(obj, x). The name is a strong convention, not a keyword.

QWhat is the difference between __repr__ and __str__?

QWhat is the difference between @classmethod and @staticmethod?

A classmethod receives the class as cls and suits alternative constructors. A staticmethod receives no implicit argument and is simply a function grouped under the class name.

QWhat is name mangling?

A name written as __x inside a class body is stored as _ClassName__x. It prevents accidental overrides in subclasses. It is not privacy, and obj._ClassName__x still works.

Python searches a class hierarchy in the order given by the C3 linearisation, stored in __mro__. super() continues along that order, which is what makes cooperative multiple inheritance work.

Interview questions

QWhat is the MRO, and how is it computed?

The method resolution order is the list of classes Python searches for an attribute, stored in Class.__mro__. It comes from C3 linearisation, which keeps each class before its bases, keeps the left-to-right order of the bases, and fails if no consistent order exists.

QWhy use super() instead of naming the base class directly?

super() follows the MRO of the instance's actual class. Naming a parent directly can call a shared ancestor twice or skip a class in a diamond hierarchy. Cooperative classes all call super().

QIs an abstract base class the same as an interface?

It plays that role. An ABC refuses to instantiate a subclass that leaves an abstract method unimplemented, and it supports isinstance checks. Pythonic code often relies on duck typing instead, so use ABCs for public contracts.

QHow does a dataclass differ from a NamedTuple or a plain class?

A dataclass generates the boilerplate methods and can be frozen. A NamedTuple is an immutable tuple with named fields, so it unpacks like a tuple. A plain class suits objects with a lot of custom behaviour.

QWhat does __slots__ buy you, and what does it cost?

Instances drop their per-object __dict__, which saves memory and makes attribute access a little faster. The cost is that you cannot add arbitrary attributes, and a subclass without its own __slots__ gets a __dict__ back.

RememberDataclass defaults

Dataclass instances are mutable unless you pass frozen=True, which suits value objects. A bare [] default raises ValueError when the class is defined, so write field(default_factory=list) instead.

PitfallDiamond hierarchies need super()

If two bases share an ancestor, a base that calls the ancestor by name can run its code twice. Calling super() everywhere keeps each method running once.

Decorators

@logged above a def means add = logged(add). The wrapper runs before and after the original. functools.wraps copies the name and docstring across, so introspection still shows the original function.

import functools

def logged(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        print(f"calling {func.__name__}{args}")
        return func(*args, **kwargs)
    return wrapper

@logged
def add(a, b):
    """Add two numbers."""
    return a + b

Generators

A function containing yield returns a generator. Each next() runs the function up to the next yield. Values are produced on demand, so memory use stays constant however long the sequence is.

Python verified run
def countdown(n):
    while n > 0:
        yield n
        n -= 1

gen = countdown(3)
print(next(gen), list(gen))
print(sum(i * i for i in range(1_000_000)))
Output
3 [2, 1]
333332833333500000

The iterator protocol

A for loop calls iter() on the object, then next() until StopIteration is raised. A class that implements __iter__ and __next__ works everywhere a built-in iterable does.

Python verified run
class Evens:
    def __init__(self, limit):
        self.limit, self.current = limit, 0

    def __iter__(self):
        return self

    def __next__(self):
        if self.current > self.limit:
            raise StopIteration
        value = self.current
        self.current += 2
        return value

print(list(Evens(5)))
Output
[0, 2, 4]

with calls __enter__ on entry and __exit__ on exit, including when an exception is raised. contextlib.contextmanager builds one from a generator; the code after yield is the cleanup.

from contextlib import contextmanager

@contextmanager
def opened(name):
    print("open", name)
    try:
        yield name.upper()
    finally:
        print("close", name)

with opened("db") as handle:
    print("using", handle)

using DB
close db

Interview questions

QWhat is a decorator?

A callable that takes a function and returns a replacement, usually a wrapper that adds behaviour. @d above def f is the same as f = d(f). Use functools.wraps so the wrapper keeps the original name, docstring and metadata.

QHow is a generator different from a list?

A generator produces values one at a time, in constant memory, and can be consumed only once. A list stores every value, supports indexing and can be iterated many times. Use a generator for large or unbounded sequences and a list when you need random access.

QWhat is the difference between yield and return?

return ends the function and gives back one value. yield suspends the function, hands a value to the caller, and resumes at the same point on the next next(). Calling a generator function returns a generator object without running its body.

QWhat does the with statement guarantee?

It calls __enter__ on entry and __exit__ on exit, even if the block raises. Files, locks and database connections use it so that cleanup cannot be forgotten.

QHow do you write a decorator that takes arguments?

Add one more layer. A factory takes the arguments and returns the decorator, which takes the function and returns the wrapper. @retry(times=3) first calls retry(times=3), and that call's result decorates the function.

PitfallForgetting functools.wraps

Without functools.wraps, the decorated function reports the wrapper's name and loses its docstring. That breaks help(), logging and some frameworks that read the name.

RememberGenerators are single-use

Once a generator is exhausted, list(gen) returns an empty list. Create a new generator, or store the values in a list, when you need to iterate twice.

Interview questions

QWhat is the difference between EAFP and LBYL?

EAFP, "easier to ask forgiveness than permission", attempts the operation and handles the exception. LBYL, "look before you leap", checks conditions first. Python favours EAFP, but exceptions are not a substitute for ordinary control flow when a failure is common.

QWhat does raise ... from err do?

QShould you catch Exception broadly?

It isolates each project's dependencies, which avoids version conflicts between projects and keeps the system Python clean. Create one with python -m venv and install into it.

Memory, the GIL & Concurrency

How CPython frees memory, what the Global Interpreter Lock means for threads, when to choose threads, processes or asyncio, and how a race condition appears.

Memory: reference counts and the cyclic collector

CPython keeps a count of references to every object. When the count reaches zero, the object is freed at once. Reference cycles never reach zero, so a separate cyclic garbage collector finds and frees them.

Python verified run
import gc
import sys

a = []
print(sys.getrefcount(a))
b = a
print(sys.getrefcount(a))
del b
print(sys.getrefcount(a))
print(gc.isenabled())
Output
2
3
2
True

The count is one higher than you might expect, because passing a to getrefcount creates a temporary reference.

The GIL

The Global Interpreter Lock lets only one thread run Python bytecode at a time in CPython. The lock is released while a thread waits on I/O, so threads still help with network and disk waits. CPU-bound threads gain nothing. Python 3.13 ships an experimental free-threaded build (PEP 703) that removes the GIL, but the standard build still has it.

Threads for I/O-bound work

    return n * n  # stands in for a call that waits on the network

    print(list(pool.map(fetch, range(5))))
Output
[0, 1, 4, 9, 16]

A race condition

counter += 1 is several bytecode steps: load, add, store. A thread switch between them loses an update. A lock makes the read-modify-write block indivisible.

Python
import threading

counter = 0
lock = threading.Lock()

def work():
    global counter
    for _ in range(100_000):
        with lock:
            counter += 1

Interview questions

QWhat is the GIL, and why does it exist?

The Global Interpreter Lock allows one thread at a time to execute Python bytecode. It keeps reference counts and interpreter state consistent without a lock on every object, and it keeps single-threaded code fast. Threads still overlap I/O waits, because the lock is released while they wait.

QThreads or processes?

Threads for I/O-bound work. Processes for CPU-bound work, through multiprocessing or ProcessPoolExecutor, because each process has its own interpreter and GIL. Processes cost more memory, and their arguments and results must be picklable.

QWhen is asyncio the right choice?

For many concurrent network or file waits inside one thread, with explicit await points. It does not speed up CPU-bound code, and a blocking call inside a coroutine stalls every other task.

QHow does Python free memory?

Reference counting frees an object as soon as its count reaches zero. The cyclic garbage collector finds unreachable reference cycles. Do not rely on __del__ for timing; use with for resources.

QWhat is a race condition, and how do you prevent one?

Two threads touch shared mutable state, and the result depends on timing. Protect the state with a lock, or avoid sharing: pass messages through a queue.Queue, or give each worker its own data.

PitfallBlocking calls inside async code

time.sleep inside an async def blocks the whole event loop. Use await asyncio.sleep, and move blocking library calls into a thread with asyncio.to_thread.

How to say itExplaining the GIL

"CPython runs one thread of Python bytecode at a time. Threads still help for I/O, but CPU-heavy work needs processes. That is why I would use a process pool for the numeric part and asyncio for the network part."

Why arrays are fast

A NumPy ndarray stores one data type in one contiguous block of memory. Interview questions

QWhy is NumPy faster than a Python loop?

Its arrays hold one type in contiguous memory, and the operations run as compiled loops, often using vector instructions. A Python loop pays interpreter overhead and object lookups for every element.

QWhat is broadcasting?

The rule that lets arrays of different shapes combine. Shapes are compared from the right, and a dimension of size 1 is stretched to match the other operand. It avoids copying data just to make shapes agree.

QWhat is the difference between a view and a copy?

A view shares the underlying memory, so writes through it change the original. A copy has its own memory. Basic slices give views, while .copy(), fancy indexing and boolean masks give copies.

QHow do you make ML experiments reproducible?

Fix the seeds you use and pass them explicitly. Pin library versions, record the configuration and the data version, and avoid parallel reductions when you need bit-identical results. Mention that GPU kernels can be nondeterministic unless configured otherwise.

PitfallRow loops in pandas

iterrows builds a Series for every row and is very slow on large frames. Express the logic as column operations, or use groupby, where or np.select.

Sliding window

Track the last index at which each character appeared. When a repeat falls inside the current window, move the left edge past it. Each index enters and leaves the window once, so the whole pass is O(n).

Python verified run
def length_of_longest_substring(s):
    last_seen = {}
    left = best = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best

print(length_of_longest_substring("abcabcbb"), length_of_longest_substring("pwwkew"), length_of_longest_substring(""))
Output
3 3 0

Breadth-first search

Python verified run
from collections import deque

def bfs(graph, start):
    seen, order, q = {start}, [], deque([start])
    while q:
        node = q.popleft()
        order.append(node)
        for nxt in graph.get(node, []):
            if nxt not in seen:
                seen.add(nxt)
                q.append(nxt)
    return order

g = {1: [2, 3], 2: [4], 3: [4], 4: []}
print(bfs(g, 1))
Output
[1, 2, 3, 4]

Interview questions

QWhy can list.pop(0) be slow?

Removing the first element shifts every other element one slot left, which is O(n). Use collections.deque and popleft() whenever the list is used as a queue.

QHow do you find the k largest elements?

heapq.nlargest(k, items) runs in O(n log k). A min-heap of size k is the streaming version: push each value, and pop whenever the heap grows past k. The heap then holds the k largest values seen so far.

QWhat is the complexity of Python's sort?

O(n log n) in the worst case. Timsort is stable, and it runs close to linear time on data that is already partly ordered, which is common in real inputs.

QWhy store seen items in a set or dict?

A membership test on a list is O(n), while a set or dict averages O(1). Replacing a list scan with a set lookup often removes a whole loop, turning an O(n²) solution into O(n).

PitfallRecursion depth

A recursive DFS on a path graph with 10⁵ nodes raises RecursionError at the default limit. Convert it to an explicit stack, or raise the limit only when you are sure the depth is bounded.

Predict the Output

Short programs whose output surprises people. Predict each result before you open the answer. Every answer is produced by running the code while this page is built.

#01

Aliasing with chained assignment

Python
a = b = []
a.append(1)
print(b, a is b)
Show answer
Output verified run
[1] True

a = b = [] binds both names to one list object, so appending through a is visible through b. The is check confirms they are the same object.

#02

Floats and comparison

Python
print(0.1 + 0.2 == 0.3, round(0.1 + 0.2, 10) == 0.3)
Show answer
Output verified run
False True

Binary floats cannot represent 0.1 or 0.2 exactly, so the sum is slightly above 0.3. Rounding to ten decimal places removes the representation error before the comparison.

#03

Floor division and modulo with negatives

Python
print(-7 // 2, -7 % 2, 7 // -2)
Show answer
Output verified run
-4 1 -4

// rounds toward negative infinity, and % takes the sign of the divisor. That keeps a == (a // b) * b + a % b true for every integer pair.

#04

A tuple holding a list

Python
t = ([1], 2)
t[0].append(3)
print(t)
Show answer
Output verified run
([1, 3], 2)

The tuple never changes, because its slots never change. The list in slot 0 is mutable, so its contents change. Assigning t[1] = 5 would raise TypeError.

#05

Dictionary keys that compare equal

Python
d = {1: "a", True: "b", 1.0: "c"}
print(d)
Show answer
Output verified run
{1: 'c'}

True and 1.0 hash and compare equal to 1, so each assignment updates the one existing key. The key stays as the first object inserted, and its value becomes "c".

#06

Identity of empty containers

Python
t, u = (), ()
print([] == [], [] is [], t is u)
Show answer
Output verified run
True False True

Each [] builds a new list, so the two lists are equal but not identical. CPython uses one shared empty tuple, so t is u is true.

#07

Chained comparisons

Python
print(3 in [1, 2, 3] == True)
Show answer
Output verified run
False

Comparison operators chain. This means (3 in [1, 2, 3]) and ([1, 2, 3] == True). The first part is true, the second is false, so the whole expression is false.

#08

Late binding in a comprehension

Python
def make():
    return [lambda: i for i in range(2)]

print([f() for f in make()])
Show answer
Output verified run
[1, 1]

Each lambda captures the variable i, not its value at creation. By the time they are called, the loop has finished with i == 1, so both return 1.

#09

A generator used twice

Python
g = (x for x in range(3))
print(list(g), list(g))
Show answer
Output verified run
[0, 1, 2] []

The first list() consumes every value. The second finds the generator already exhausted and returns an empty list.

#10

Strings are not changed by methods

Python
s = "  hi  "
s.strip()
print(repr(s))
Show answer
Output verified run
'  hi  '

strip() returns a new string, and the result was thrown away. The original keeps its spaces, and repr shows them.

#11

Which operations return floats

Python
print(type(1 / 1), type(1 // 1), type(2 ** -1))
Show answer
Output verified run
<class 'float'> <class 'int'> <class 'float'>

/ always produces a float. // on two ints produces an int. A negative exponent on an int produces a float, because the result is a fraction.

#12

In-place addition versus rebinding

Python
x = [1, 2, 3]
y = x
x += [4]
x = x + [5]
print(x, y)
Show answer
Output verified run
[1, 2, 3, 4, 5] [1, 2, 3, 4]

+= on a list extends the same object, so y sees the change. x + [5] builds a new list and rebinds x, so y keeps the earlier list.

#13

Comparing strings

Python
print("a" < "B", "a".upper() < "B")
Show answer
Output verified run
False True

String comparison uses code points, and "a" is 97 while "B" is 66. Uppercasing "a" gives 65, which is below 66.

#14

One list under two keys

Python
d = dict.fromkeys("ab", [])
d["a"].append(1)
print(d)
Show answer
Output verified run
{'a': [1], 'b': [1]}

dict.fromkeys stores the same list object under every key. Appending through one key shows up under all of them. Use a dict comprehension to create a separate list per key.

#15

Truthiness of strings

Python
print(bool("False"), bool(False), bool([False]))
Show answer
Output verified run
True False True

Only empty containers are false. The string "False" is non-empty, so it is true, and a list holding False is also non-empty.

Cheat sheet

  • Costs: list append O(1) amortised, in on a list O(n), dict and set operations O(1) average, deque at either end O(1), heap push and pop O(log n), sorted O(n log n).
  • Idioms: enumerate, zip, dict.get, setdefault, defaultdict(list), Counter.most_common, sorted(key=...), f"{x=}", with, try/except/else/finally.
  • Traps: mutable default arguments, shallow copies of nested lists, late binding in lambdas, is versus ==, float rounding, += on a list shared by two names, generators that are exhausted after one pass.
  • Concurrency: threads for I/O, processes for CPU, asyncio for many waits in one thread, and a lock around any read-modify-write on shared state.
